An open-source remote desktop application, the open source TeamViewer alternative.
Source code: https://github.com/runseal-labs/sealdesk

In order for a remote device to control your Android device via mouse or touch, you need to allow SealDesk to use the "Accessibility" service. SealDesk uses the AccessibilityService API to implement Android remote control.

In addition to remote control, you can also transfer files between Android devices and PCs easily with SealDesk.

You have full control of your data, with no concerns about security.

Please download and install the desktop version from https://github.com/runseal-labs/sealdesk, then you can access and control your desktop from your mobile, or control your mobile from the desktop.
