开源远程桌面应用，开源 TeamViewer 替代方案。
源代码：https://github.com/runseal-labs/sealdesk

为了让远程设备通过鼠标或触摸控制您的 Android 设备，您需要允许 SealDesk 使用“Accessibility”服务。SealDesk 使用 AccessibilityService API 来实现 Android 远程控制。

除了远程控制，您还可以使用 SealDesk 在 Android 设备和 PC 之间轻松传输文件。

您完全掌控数据，不用担心安全问题。

请从 https://github.com/runseal-labs/sealdesk 下载并安装桌面版，然后您可以通过手机访问和控制您的桌面，或从桌面控制您的手机。

SealDesk 是 RustDesk 的修改版本，以 AGPL-3.0 许可发布。
